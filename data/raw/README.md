# data/raw

Сюда команда помещает неизменные локальные входы, если это допускают правила доступа:

- KB export;
- официальный Регламент;
- PDF-инструкции/приложения;
- обезличенную историю обращений;
- taxonomy/crosswalk;
- существующий lab-code или ссылку на его repository path.

Не коммитьте закрытые/крупные данные автоматически. Зафиксируйте имя, путь, владельца, формат и SHA-256 в docs/integration/input_inventory.md. Агенты не переписывают этот каталог.
